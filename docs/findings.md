# 核心发现

以下五条是当前数据与口径能够稳定支持的公开结论。指标定义见[指标定义](metric_definitions.md)，数据边界见[数据质量与分析限制](data_quality_and_limitations.md)。

## F1 首次到达核心体验后，重复使用仍有明显缺口

**结论**  
一次到达核心体验不等于形成早期重复使用，首日连续体验是独立的增长问题。

**证据**  
257,314名新设备用户中，50,940人在首会话完成主激活，主激活率19.80%；拥有完整24小时观察窗的255,188名用户中，29,543人达到有意义激活，比例为11.58%。

**业务解释**  
产品应在首次核心体验之后提供清晰的继续入口、下一步推荐或轻量任务，帮助用户形成第二次核心行为。

**限制**  
当前核心价值由电商事件映射，迁移到其他产品时需要重新确认事件角色。

## F2 最大漏斗损失发生在核心价值到高意向之间

**结论**  
相较结账环节，核心体验后的价值理解与下一步意向形成具有更高优化优先级。

**证据**  
严格有序会话漏斗为77,020 → 12,883 → 4,420 → 2,313。核心价值到高意向的阶段通过率为16.73%，低于后续阶段的34.31%和52.33%。

**业务解释**  
优先测试价值说明、推荐路径和高意向入口，比只优化结账页面更贴近当前主要损失位置。

**限制**  
2,263个核心价值与高意向同时间戳会话因顺序未知未计入严格下一阶段。

## F3 用户返回率随时间快速下降

**结论**  
样例中的重复使用绝对水平较低，扩大流量不会自动形成长期用户。

**证据**  
产品返回率从D1的2.28%下降至D7的0.49%和D30的0.11%；各观察日均使用具备完整窗口的成熟用户作为分母。

**业务解释**  
首日回访触发、体验连续性和第二次核心体验应成为留存实验的优先方向。

**限制**  
数据仅覆盖92日，不能外推更长期的留存水平。

## F4 早期重复核心行为与未来转化质量强相关

**结论**  
首访后24小时内重复核心行为是值得纳入实验的候选激活深度信号。

**证据**  
在170,413名拥有完整30日结果窗的用户中，重复核心行为组的未来转化率为2.81%，未发生组为0.22%；绝对差为2.60个百分点，风险比为12.91。

**业务解释**  
可以把“完成第二次核心行为”作为激活实验的中间指标，并继续观察固定窗口转化与留存。

**限制**  
该差异可能反映用户原有意图，只能视为观察性关联。

## F5 转化事件不能直接替代可识别用户价值

**结论**  
事件转化、有效订单与正已识别价值需要分开治理和报告。

**证据**  
固定30日成熟窗口内有938名转化用户，其中879名能够关联有效订单、确认收入并产生正已识别价值，差异为59人；已识别收入为84,133美元。

**业务解释**  
产品目标应同时监控转化率、订单可识别率和正价值用户率，避免把埋点事件直接当作可审计收入。

**限制**  
数据不含退款、成本和利润，因此正已识别价值不等于净业务价值。
