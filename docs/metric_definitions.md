# 指标定义

本文统一说明项目中使用的核心指标口径、分析粒度与时间窗口。分析结果、策略和技术说明只引用这里的名称，不重复完整定义。

## 核心用户与会话口径

| 指标 | 定义 | 粒度/分母 | 时间窗口 | 注意事项 |
|---|---|---|---|---|
| 用户 | 去重 `user_pseudo_id` | 设备级用户 | 数据窗口 | 不代表跨设备自然人 |
| 会话 | `user_pseudo_id + ga_session_id` 的唯一组合 | 会话 | 数据窗口 | 不以 `session_start` 事件数代理会话数 |
| 新用户 | 至少发生一次 `first_visit` 的用户 | 去重新用户 | 数据窗口 | 同期群日期取最早 `first_visit` 的 `event_date` |
| 首次接触渠道 | 用户级 `traffic_source.source / medium / name` | 新用户 | 首次接触 | 缺失值与脱敏值保留为独立质量类别 |
| 参与会话 | 会话内标准化 `session_engaged = 1` | 会话 | 单次会话 | 用于产品返回判定 |

## 行为、激活与转化口径

| 指标 | 定义 | 粒度/分母 | 时间窗口 | 注意事项 |
|---|---|---|---|---|
| 核心价值 | 当前映射为 `view_item` 的通用价值事件 | 事件或会话 | 依分析模块 | 跨产品迁移时需重新映射 |
| 高意向 | 当前映射为 `add_to_cart` 的通用意向事件 | 事件或会话 | 依分析模块 | 不等同于最终转化 |
| 开始结账 | 当前映射为 `begin_checkout` | 事件或会话 | 依分析模块 | 仅为当前业务载体中的中后段行为 |
| 转化 | 当前映射为 `purchase` 的结果事件 | 事件、会话或用户 | 依分析模块 | 不自动等同于有效订单或正价值 |
| 主激活率 | 首会话内至少一次核心价值事件的用户数 / 新用户数 | 新用户 | 首会话 | 衡量首次体验是否到达核心价值 |
| 有意义激活率 | 24小时内至少两次核心价值事件的用户数 / 完整24小时特征窗用户数 | 新用户 | 首访后24小时 | 不成熟用户为 `NULL`，不归入未发生组 |
| 深度激活率 | 24小时内发生高意向事件的用户数 / 完整24小时特征窗用户数 | 新用户 | 首访后24小时 | 衡量早期意向深度 |
| 严格有序阶段率 | 严格到达下一阶段的会话数 / 严格到达当前阶段的会话数 | 会话 | 同一会话 | 后一步首次时间戳必须严格晚于前一步 |
| 严格有序端到端率 | 严格完成转化的会话数 / 严格到达核心价值的会话数 | 会话 | 同一会话 | 时间戳相同视为顺序未知 |
| 实际日历月漏斗 | 按会话真实 `session_date` 月份汇总严格漏斗 | 会话 | 日历月 | 回答时期表现变化 |
| 获客同期群首会话漏斗 | 按用户获客月汇总其首会话严格漏斗 | 新用户首会话 | 获客月 | 不混入后续不限期会话 |

## 留存与生命周期

| 指标 | 定义 | 粒度/分母 | 时间窗口 | 注意事项 |
|---|---|---|---|---|
| Dn 产品返回率 | 第 n 个报表自然日存在参与会话的用户数 / Dn 成熟用户数 | 用户 × 同期群 × 日偏移 | 精确第 n 自然日 | 不是 n 日内累计返回 |
| Dn 核心行为返回率 | 第 n 个报表自然日再次发生核心价值事件的用户数 / Dn 成熟用户数 | 用户 × 同期群 × 日偏移 | 精确第 n 自然日 | 与产品返回分别报告 |
| Dn 成熟用户 | `cohort_date + n <= data_end_date` 的新用户 | 用户 | 对应 Dn | 未成熟结果为 `NULL` |
| 历史最高阶段 | 用户在观察期内达到的最高业务阶段 | 新用户 | 全观察期 | 顺序为新用户、已参与、核心价值、高意向、已转化 |
| 活跃 | 快照日及之前6天存在参与会话 | 新用户/全部新用户 | 最近7日 | 与其他活跃状态互斥 |
| 未成熟 | 最近7日无参与且观察不足8日 | 新用户/全部新用户 | 快照回看 | 不进入降温或沉寂监控分母 |
| 近期未活跃 | 最近7日无参与，但快照日前8–29日存在参与会话 | 观察至少8日的用户 | 快照回看 | 与沉寂率分母不同，不可相加 |
| 沉寂 | 观察至少30日且最近30日无参与会话 | 观察至少30日的用户 | 快照回看 | 状态构成率与监控率需区分 |

## 订单与用户价值

| 指标 | 定义 | 粒度/分母 | 时间窗口 | 注意事项 |
|---|---|---|---|---|
| 有效交易编号 | 非空、非空字符串且不为 `(not set)` 的 `transaction_id` | 购买事件 | 数据窗口 | 占位编号不进入订单键 |
| 规范订单 | `user_pseudo_id + event_date + 有效交易编号` 的唯一组合 | 订单 | 数据窗口 | 重复上报先聚合再判定收入 |
| 可识别订单用户率 | 至少拥有一个规范订单的用户数 / 对应合格用户数 | 用户 | 对应分析窗口 | 与转化事件分别报告 |
| 收入可识别订单 | 规范订单内恰好存在一个不同非空收入值 | 订单 | 数据窗口 | 全空收入和冲突收入不进入主收入 |
| 收入冲突订单 | 规范订单内存在多个不同非空收入值 | 订单 | 数据窗口 | 保留订单，主收入记空 |
| 已识别收入 | 所有收入可识别订单的收入合计 | 订单聚合 | 对应分析窗口 | 合法零收入保留 |
| 正已识别价值用户率 | 已识别收入合计严格大于0的用户数 / 对应合格用户数 | 用户 | 对应分析窗口 | 不以转化事件存在代理 |
| 已识别客单价 | 已识别收入 / 收入可识别订单数 | 订单聚合 | 对应分析窗口 | 收入未知或冲突订单不进入分母，合法零值进入 |
| 每合格用户价值 | 已识别收入 / 对应合格用户数 | 用户总体 | 对应分析窗口 | 用于固定窗口的总体价值比较 |

固定未来结果窗统一为 `[首访+24小时, 首访+30日)`，只纳入拥有完整30日结果窗的用户。窗口内分别报告转化、可识别订单、收入可识别和正已识别价值，不互相代理。

## 时间口径与合格分母

- 日历日、同期群日期与精确日留存使用 GA4 `event_date`，代表属性报表时区中的日期。
- 事件顺序及24小时、30日滚动窗口使用 `event_timestamp` 的精确时间差。
- 合格分母是具备完整特征窗或结果窗的用户集合；窗口未成熟者保留为未知，不视为未发生。
- 早期行为特征窗在首访后24小时结束，未来结果窗从该时点开始，避免同窗信息泄漏。
